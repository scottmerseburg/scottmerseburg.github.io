Baggage Scanner Shader

Overview and introduction

Breakdown on how the shader works and how its made.

Introduction

This project explores how to recreate the look of an airport baggage scanner in Unity using Shader Graph. The goal was to visualize the contents inside luggage by showing internal objects, material types, and thickness. To achieve this, I combined transparency, fresnel effects, thickness maps, and material ID textures.

Textures and effects used

Here is a breakdown of how each indivudual object works.

  • Thickness Map — Texture to illustrate the objects thickness
  • Material Map — Material Map to map a color to each part of the object
  • Fresnel Effect — Fresnel effect to get the seethrough scanned look
  • Final Shader — Conbinding all of the above to get the Baggage scan effect

Stencil and depth buffers

Breakdown of how the scanning effect works.

  • Occlusion Box — I use a simple invisible box to detect when the bag is hidden behind other geometry. This determines when the scan should activate. and shader material will bw applied.
  • Stencil Mask — When the bag is occluded, I write to the stencil buffer to mark exactly where the effect is allowed to appear.
  • Content inside — Finally, I render the contents of the bag, but only inside the stencil mask, making them visible only when the scan is active.

Breakdown

Breakdown on how the shader works and how its made.

Thickness Texture

Created in Substance Painter, this texture represents the thickness of the object using grayscale values based on ray-cast depth. Darker areas indicate thicker parts of the mesh, while lighter areas represent thinner sections.

Material Texture

This texture was created to define different material types across the object. Using grayscale values, different areas are assigned material categories such as Organic, Non-Organic, Metals, and Heavy Metals. In the shader, these values are masked and remapped to the correct material colors, which are controlled through global parameters.

Fresnel Effect

Fresnel is a effect that takes camera position to account and not draws pixles that have the normals to the camera. This is used in the shader to create glowing edges on the objects. The frensel effect is added with the material color and put into the emmissive input in the master stack reslulting in a glowing edge around the objects

Final Shader

So the final shader is a combination of all these effects the thickness texture is combined with the material texture to create a albedo map that is connected to the base map in the main shader input. The Fresnel and material cobination is added to the emmisive to create a glowing edge.

Occlution and stencil buffer

The red box represents the occluder a simple invisible proxy used to detect when the bag is behind other geometry. When this happens, I write a value to the stencil buffer to mark the active scan area. The white material is a debug visualization of the stencil mask. It shows exactly where rendering is allowed. In the final version, this area is instead filled with the transparent X-ray material. Finally, both the bag and its contents are rendered only inside this masked region, making them visible only when the scan is active.

Challanges

  • A large part of the work happened outside of Unity. There was a lot of preparation involved, including fixing UV maps for the objects, baking thickness maps for each asset, and creating material textures for every object.
  • Another challenge was achieving the right transparent look. Visually, the thickness information baked in Substance Painter did not always reflect the actual thickness in a believable way, so it required a bit of testing and adjustment.
  • Since i havent worked alot with render passes, buffers or stencils Understanding and getting the shader to render when it was suppose too took abit of reaserch and testing.

If i had more time

  • If I had more time, I would have liked to explore further automation to reduce the amount of preparation work. For example, I would have wanted to develop a tool inside the engine that could automatically calculate the thickness of the entire baggage. I also would have liked to make the shader setup more automatic, so that the whole bag could use a single material instead of requiring one material per object.
  • It would also have been nice to spend more time polishing the visual look. I think there is potential for more interesting results by basing color values on the density of each object, making them appear darker or lighter depending on the data. I also would have liked to experiment with post-processing effects to create more of a scanner-like feel.
